# 🎄 Christmas Lights (Java)

Projeto desenvolvido em Java utilizando Swing que simula um efeito de luzes de Natal animadas.

## 📌 Descrição

A aplicação desenha uma sequência de círculos que mudam de intensidade ao longo do tempo, criando um efeito visual semelhante a luzes decorativas de Natal.

## 🚀 Funcionalidades

- ▶️ Iniciar e parar animação
- ⏱️ Controle de velocidade
- 🎨 Escolha de cores (bônus)
- 🔆 Controle de intensidade (bônus)
- 🔵 Ajuste de tamanho dos círculos (bônus)
- 📊 Suporte a múltiplas linhas (bônus)

## 🛠️ Tecnologias utilizadas

- Java
- Swing (GUI)
- Timer (animação)

## 🧠 Conceitos aplicados

- Programação orientada a objetos
- Event-driven programming
- Renderização gráfica com `paintComponent`
- Animação baseada em tempo
